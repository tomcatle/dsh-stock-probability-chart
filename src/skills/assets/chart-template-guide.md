# 概率图模板填充说明

读取 `assets/probability-chart-template.svg`，把 `{{...}}` 占位符全部替换后，
按宿主可用能力渲染：优先内联预览；若无内联能力，写成 `<股票代码>_情景概率图.svg` 文件
并用宿主的预览/呈现能力展示。无论哪种方式，图内都必须包含"主观估计，非统计回测"字样。

## 占位符清单

| 占位符 | 含义 | 示例 |
|---|---|---|
| `STOCK_NAME` | 股票简称 | 海看股份 |
| `STOCK_CODE` | 带市场后缀代码 | 301262.SZ |
| `PERIOD` | 绝对时间区间 | 下周（11/23–11/27） |
| `BASE_PRICE` | 基准价 | 20.70 |
| `BASE_TYPE` | 基准类型 | 11/20 午盘快照，非收盘价 |
| `R1` | 上方第一阻力（强势档下界） | 21.92 |
| `R1_LABEL` | 强势档描述 | 站上MA5 |
| `R2_LOW` / `R2` | 温和收阳区间 | 20.70 / 21.92 |
| `R2_LABEL` | 温和档描述 | 温和收阳 |
| `R3_LOW` / `R3` | 收阴整理区间 | 19.00 / 20.70 |
| `R3_LABEL` | 收阴档描述 | 收阴整理 |
| `R4` | 下方支撑（破位档上界） | 19.00 |
| `R4_LABEL` | 破位档描述 | 破位 |
| `P1`~`P4` | 四档概率整数（和为100） | 20 / 20 / 35 / 25 |
| `W1`~`W4` | 横条宽度（像素） | 见下 |
| `T1X`~`T4X` | 概率文字 x 坐标 | 见下 |
| `P_UP` / `P_DOWN` | 收阳/收阴合计 | 40 / 60 |
| `SUMMARY_STAT` | 一句关键统计 | 站上 MA5 仅 20% |
| `BIAS_NOTE` | 一句话倾向判断 | 超卖反抽存在，但空头排列+资金流出，弱势震荡为主 |

## 条宽与文字坐标计算（必须按此算，不要目测）

- 条宽 `W = P × 7`（像素），横条起点固定 x=200。
- 概率文字 x 坐标 `TX = 200 + W + 8`。
- 校验：最大概率若 40%，W=280，文字 x=488；若 35%，W=245，文字 x=453。
- 四档概率之和必须为 100，否则图内合计行会与条形不一致。

## 颜色映射（A 股红涨绿跌，禁止反用）

- 强势上涨档：`#E24B4A`（深红），文字 `#A32D2D`
- 温和收阳档：`#F09595`（浅红），文字 `#A32D2D`
- 收阴整理档：`#C0DD97`（浅绿），文字 `#3B6D11`
- 破位下跌档：`#639922`（深绿），文字 `#3B6D11`

## 渲染前自检

- 确认所有 `{{` 和 `}}` 已被替换（可 grep 检查）。
- 确认 `viewBox` 仍为 `0 0 680 310`，未改动。
- 确认图内有"主观估计，非统计回测"字样。
- 确认基准价是否盘中已在副标题标注。
