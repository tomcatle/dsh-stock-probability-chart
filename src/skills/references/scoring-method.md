# 短周期股价情景概率估计方法

## 方法定位（必须先读）

本方法产出的是**结构化主观概率估计**（structured subjective probability estimate），
不是统计回测模型，不是量化因子信号，没有历史胜率支撑，也不满足任何统计显著性要求。
它的价值在于：**用一套固定流程把散乱的多空信号收敛成互斥完备的情景概率**，
从而避免"感觉要涨"式的拍脑袋，并让每次判断可复核、可追溯、可对比。

对用户输出时，必须明确说明这一点，禁止把估计结果表述为"历史回测显示上涨概率 XX%"。
凡是把主观估计伪装成统计结论的表述，一律视为红线违规。

## 适用场景与不适用场景

**适用**：用户问"X 股下周/未来 N 天上涨概率多大""趋势评估""能不能持仓过周末"
"短期方向判断"等，且时间窗在 1 周至 1 个月（约 5-22 个交易日）。

**不适用**：
- 长期（数季度以上）投资价值判断 → 本方法不适用
- 用户只要单点目标价 → 不给点位预测
- 用户只想买卖操作 → 本方法只提供概率输入

## 核心工作流（六步）

### 第 1 步：锁定基准与口径（不可跳过）

- **先确认交易状态**：当前时间是否在交易时段？盘中快照不是收盘价。
  必须明确写出"基准为 X 日盘中快照，非收盘价；收盘后需重算"。
- **定义"上涨"**：默认指目标周期最后一个交易日的收盘价 > 基准价。
  若用户另有定义（如单日涨幅 > 5%），按其定义并在输出中显式声明。
- **锁定时间窗**：把"下周"等相对时间换算为绝对交易日区间，并核对是否有
  解禁、减持窗口、财报、重要政策落地等事件落在窗口内或紧邻窗口。

### 第 2 步：取数（按宿主环境能力逐级降级）

优先使用当前环境已连接的金融数据工具/MCP；若无，用联网搜索工具检索行情、公告、资金数据；
再兜底浏览器打开权威页面。不要假设存在某个特定工具名。
必须取到以下六类信号，缺任一类要在输出中标注"数据未覆盖"而非编造：

| 信号类别 | 关键指标 | 时效要求 |
|---|---|---|
| 趋势结构 | 现价 vs MA5/10/20/60/250、均线排列、MACD | 最近收盘或盘中 |
| 超买超卖 | KDJ 的 J 值、RSI6、布林上中下轨 | 同上 |
| 资金流向 | 主力当日/近5日/近10日净流入、超大单结构 | 最近交易日 |
| 杠杆与筹码 | 融资余额变化、股东户数变化、换手率 | 最近披露期 |
| 事件窗口 | 解禁（股数/占比/日期）、减持窗口、财报日 | 公告口径 |
| 板块环境 | 所属题材处于预热/启动/发酵/高潮/退潮哪一段 | 最近交易日 |

所有数字必须带来源 + 时点；研报/媒体数字标注"非一手来源，需核实原文"。
若当前环境无联网能力，停止给概率，仅输出方法论框架并说明数据缺失。

### 第 3 步：给每条信号定方向（多/空/中性）与强度

强度分三档：强 / 中 / 弱。判定标准：

- **强**：趋势级信号（均线空头/多头排列、MACD 死叉/金叉）、大额资金连续净流出/流入、
  大额解禁（占总股本 > 30%）、监管或政策落地。
- **中**：单日资金转向、融资余额连续 2-3 日变化、股东户数单月变化 > 10%、
  板块进入退潮/发酵期。
- **弱**：超卖/超买读数、单日反抽、单个公司互动平台表述。

注意：**超卖是"弱"级反抽信号，不是趋势反转信号**。这是本方法最常见的高频误判。
KDJ 的 J 值为负、RSI6 < 30 只支持"技术性反抽"，不能单独把上涨概率拉到 50% 以上。

### 第 4 步：多空加权得到方向基调

- 把"强/中/弱"分别记为 3/2/1 分，多空两侧分别求和。
- 计算多方占比 = 多方分 /（多方分 + 空方分）。
- **概率基调锚点**：多方占比直接作为"收阳概率"的一阶近似，但要做第 5 步校准。

本方法实测示例（海看股份，2026-11-20）：
多方（超卖弱 + 支撑弱 + 单日资金流入中 + 回撤幅度中）≈ 7 分；
空方（均线空头强 + MACD 死叉强 + 主力5日净流出强 + 融资下降中 + 减持中 + 解禁强 + 板块退潮中）≈ 18 分；
多方占比 ≈ 28%，校准后收阳概率取 40%（见下条为什么上修）。

### 第 5 步：贝叶斯校准（关键，避免机械套公式）

在一阶近似上做以下调整，每次调整都要写出理由：

1. **超卖下限保护**：处深度超卖且有关键均线/前低支撑时，把收阳概率上修 5-10 个百分点，
   同时把"破位"概率压低 5-10 个百分点——原因是下跌动能在短期内衰减，但趋势未反转。
2. **事件提前反应**：解禁/减持窗口临近时，把"冲高"情景概率下修，
   把"弱势整理/破位"上修——市场通常提前 2-3 周反应，不要等到事件当天。
3. **板块环境乘数**：板块处退潮期时，个股独立走强概率打 5 折；处启动/发酵期可上浮 10 个百分点。
4. **校准后必须归一化**：所有互斥情景概率之和严格等于 100%，四档情景通常取 20/20/35/25 这类整数组合，
   不要出现 33.3% 这种虚假精度。

**禁止行为**：不要为了"看起来有依据"而把概率写成 43.7% 这类精确值。
概率必须用 5% 为步长的整数，并在输出中说明是主观估计。

### 第 6 步：映射为互斥完备的四个情景

四档情景必须**互斥**（不重叠）且**完备**（穷尽所有收盘价可能），按收盘价划分区间：

1. 强势上涨：收盘价 > 上方第一阻力（通常是 MA5 或 MA20）
2. 温和收阳：基准价 < 收盘价 ≤ 上方第一阻力
3. 收阴整理：下方支撑 ≤ 收盘价 ≤ 基准价
4. 破位下跌：收盘价 < 下方支撑（通常是前低或布林下轨）

四档概率之和 = 100%。收阳概率 = 情景 1 + 情景 2。

## 输出结构（固定四段式）

1. **口径声明**：基准价、是否盘中、时间窗绝对日期、"主观估计非统计回测"三件事必须前置。
2. **情景概率图**：用 `assets/probability-chart-template.svg` 填数，按宿主可用能力内联渲染或写成 SVG 文件预览。
3. **多空信号对照表**：分列支持/压制两组，每条带具体数字与时点，不写空泛的"利好/利空"。
4. **结论与持仓含义**：给出收阳/收阴概率、加仓/止损触发条件、下周需盯的可验证变量。

结尾附加 SKILL.md 中的固定免责声明，禁止改写。

## 常见偏差（每次输出前自检）

- **把超卖当反转**：最高频错误，见第 3 步。
- **概率不互斥**：例如同时给出"上涨 40%"和"站上 MA5 30%"，这两个有重叠。必须用区间划分。
- **忽略时间窗内的事件**：解禁/减持窗口落在窗口内却没进概率校准。
- **虚假精度**：出现小数概率、不带来源的数字、"统计显示"字样。
- **基准错位**：用盘中价当收盘价、用 T 日数据算 T+1 概率而没做标注。
- **幸存者视角**：只列支持自己结论的信号，反向信号必须单独成列。

## 可视化规范摘要

概率图用 SVG 横条，遵循以下规范（与宿主无关）：
- viewBox 固定 `0 0 680 310`，宽度 100%，背景透明。
- A 股语境红涨绿跌：上涨档用红色系（#E24B4A / #F09595），下跌档用绿色系（#C0DD97 / #639922）。
- 条宽按概率线性映射（示例：40% 对应 280px，即 7px/百分点）。
- 标题 14px/500，正文 12-13px/400，禁止低于 11px，禁止字重 600 以上。
- 图内必须标注基准价是否盘中、四档概率、收阳合计与一句话倾向。
- 具体数值和来源写在对话正文，不塞进图里。
